.. _whatsnew_023:

0.2.3 (not yet released)
------------------------


Enhancements
~~~~~~~~~~~~
* :py:func:`pvanalytics.features.clearsky.reno` can now infer the window
  length and threshold values from the time interval of the data
  (``infer_limits=True`` in :py:func:`pvlib.clearsky.detect_clearsky`),
  and can accept data at intervals of 1 to 30 minutes. The docstring now
  notes that the function can be applied to plane-of-array irradiance.
  (:issue:`222`, :pull:`239`)

Bug Fixes
~~~~~~~~~
* :py:func:`pvanalytics.features.clearsky.reno` now correctly passes
  ``window_length`` to the underlying pvlib function. (:pull:`221`)
* Remove freq parameter from :py:func:`pvanalytics.quality.gaps.completeness`
  and :py:func:`pvanalytics.quality.gaps.completeness_score`. Frequency is now
  always calculated from the input data's DatetimeIndex. (:pull:`236`) 

Requirements
~~~~~~~~~~~~
* Advance minimum python to 3.10, and the following dependencies (:pull:`220`, :pull:`228`):

  - numpy: 1.21.2
  - pandas: 1.3.3
  - scipy: 1.7.2
  - statsmodels: 0.13.1
  - scikit-image: 0.19.0

* Advance minimum pvlib to 0.13.1, which is needed for
  :py:func:`pvanalytics.features.clearsky.reno`. (:issue:`222`, :pull:`239`)
